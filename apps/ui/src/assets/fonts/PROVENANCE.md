# Fonts

**Vazirmatn** by Saber Rastikerdar — [SIL Open Font License 1.1](https://github.com/rastikerdar/vazirmatn/blob/master/OFL.txt).
Version 33.003, variable weight axis, `Vazirmatn[wght].woff2`.

The OFL permits bundling in any software, commercial or not, provided the font
itself is not sold on its own and the licence travels with it. That is satisfied
by this file.

One family covers both Persian and Latin, which is the point: switching the
interface language must not change how the numbers look. Self-hosted rather than
loaded from a CDN, because the app has to work with the machine offline.
